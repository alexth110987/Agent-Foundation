# Permissions — Design Placeholder

**Status:** Not implemented. No tools or external integrations are currently approved.

Apply least privilege and deny by default. A workflow's existence does not grant access to tools or data.

For each future capability, document its purpose, permitted actor or workflow, resource and data scope, allowed and prohibited operations, approval requirements, expiry or revocation method, and audit evidence.

External communication, publication, purchases, financial actions, data sharing, deletion, destructive modification, and irreversible actions require explicit authorization before execution.

Do not store credentials in this repository.
